# Posibles ampliaciones futuras:

### Módulos adicionales:
* efemerides.m - Efemérides solares/lunares más precisas (Completado: **12/10/2025** - **Versión 1.1.0**)
* constelaciones.m - Identificación de constelaciones (**Versión 1.2.0**)

  1. Expansión del catálogo: 
  
     - Las 88 constelaciones oficiales IAU
     - Más estrellas brillantes (hasta magnitud 4.0)
     - Objetos de cielo profundo (nebulosas, cúmulos)

  2. Funciones de visualización:
     
     - Mapas estelares simples en coordenadas
     - Líneas entre estrellas para formar figuras
     - Posiciones actuales en tiempo real

  3. Herramientas de observación:
     
     - Constelaciones del zodiaco y efemérides
     - Recomendaciones según fecha/hora
     - Condiciones de visibilidad (contaminación lumínica)

  4. Integración con efemérides:
     
     - Constelaciones en culminación para una fecha
     - Mejor hora de observación para cada constelación
     - Relación con posición lunar/planetaria

* catalogos.m - Acceso a catálogos estelares básicos
* observacion.m - Herramientas de planificación observacional
* orbitas.m - Cálculos orbitales más avanzados

### Mejoras técnicas:
* Sistema de configuración para ubicación del observador
* Manejo de diferentes sistemas de coordenadas
* Interfaz gráfica básica para cálculos comunes
* Exportación de datos a formatos estándar
* Funciones básicas de cálculo escritas en C++ (archivos .oct)

### Integración con datos externos:
* Conexión con APIs astronómicas públicas
* Importación de formatos FITS básicos
* Catálogos de objetos Messier/NG
